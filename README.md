# smarbo.xyz

Personal site for [smarbo.xyz](https://smarbo.xyz) (GitHub Pages).

Static single-page site: `index.html`, `style.css`, `main.js`.

## Local preview

```bash
# Python
python -m http.server 8080
# open http://localhost:8080
```

## Deploy

Push to `main` on `smarbo/smarbo.github.io`. GitHub Pages serves from this repo; custom domain is set via `CNAME` → `smarbo.xyz`.
